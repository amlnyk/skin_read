## Ризики, які лишаються

1. **Ліміт у пам'яті функції.** Кожен холодний старт і другий екземпляр рахують з нуля. Від масового зловживання захищає лише ліміт витрат в обліковому записі Anthropic. Надійно: Upstash Redis або Vercel KV за інтерфейсом `RateLimiter` (змінюється один файл).
2. **Не-браузерні клієнти** підробляють `Origin`. Перевірка Origin не є автентифікацією; тому ліміти обов'язкові.
3. **Дані про здоров'я на пристрої** (стан шкіри, реакції, цикл) лежать у `localStorage` і IndexedDB без шифрування. Будь-хто з доступом до розблокованого браузера їх бачить; браузерні розширення з доступом до сайту теж. Для MVP без акаунтів це прийнятно, і екран «Конфіденційність» про це каже.
4. **Фото йде до стороннього ШІ** після окремої згоди. Що постачальник робить із даними, визначають його умови; формулювання згоди потребує юридичної перевірки (`CONTENT_TODO.md`, етапи 11 і 13).
5. **Prompt injection** на реальних етикетках не перевірено. Модель без інструментів і без доступу до профілю, відповідь перевіряє схема, клієнт показує текст як текст, тому найгірший наслідок це хибний склад, який людина бачить на екрані перевірки.
