# Відповідність ТЗ (звірка етапу 14)

Джерело: `content/source/message.txt` (ТЗ, розділи 01–39). Дата звірки: 2026-11-25, версія `1.0.0`.

Позначки: **так**: реалізовано й покрито автотестами; **частково**: реалізовано не все або з обмеженням; **контент**: код готовий, але без матеріалів косметолога на справжніх даних не працює; **ні**: не реалізовано (з причиною).

## Головний висновок

Код виконує всі пункти P0 і майже всі P1. Найбільша прогалина не в коді, а в контенті: **у базі немає жодної картки інгредієнта і жодного правила сумісності** (є лише заготовки). Перевірка: склад `Aqua, Glycerin, Niacinamide, Butylene Glycol, Retinol, Salicylic Acid, Sodium Hyaluronate, Panthenol, Ceramide NP, Phenoxyethanol, Parfum, Alcohol Denat.` на справжньому контенті розпізнає лише `Parfum` (група «ароматизатори» за шаблоном); решта «невідомі». Тому на справжніх даних сканер чесно відповідає «Недостатньо інформації», а критерії готовності 9–11 (розділ 35) можна показати лише на тестових даних. Це свідоме правило ТЗ (розділ 32: не доповнювати базу неперевіреним текстом від мовної моделі). Потрібна база «декількох десятків поширених компонентів» від косметолога.

**Оновлення (той самий день):** додано таблиці для косметолога й `npm run content:import` (`docs/content-guide.md`) і 93 компоненти з довідковими даними (назви й групи, без порад, чернетки). Той самий склад тепер розпізнається повністю в демонстраційному режимі. Пояснень, застережень і правил сумісності так само немає: це робота косметолога.

## Що з цього випливає для презентації

- Аналіз складу на справжніх даних поки скаже «Недостатньо інформації» майже для всього. Перед показом потрібні хоча б 20–30 карток поширених компонентів і кілька правил сумісності від косметолога (у форматі `ingredients.json` і `compat-rules.json`). Вигадувати їх у застосунку не можна (ТЗ, розділ 32). Логіку на вигаданих даних можна показати лише як тести, а не як роботу застосунку.
- `npm run content:audit -- --strict` не проходить (0 перевірених записів); список бракуючого: `CONTENT_TODO.md`.
