# Як наповнити базу компонентів (для косметолога й авторки)

Застосунок розпізнає склад засобу лише за тими компонентами, які є в базі. Що компонент робить, кому може не підійти і з чим його не варто поєднувати, пише **лише фахівчиня**. Застосунок нічого з цього не вигадує й не доповнює.

## Три таблиці

Лежать у теці `content/cosmetologist/`. Відкриваються в Excel або Google Sheets.

| Файл | Що в ньому |
|---|---|
| `ingredients.csv` | компоненти: один рядок = один компонент |
| `compat-rules.csv` | правила сумісності: один рядок = одна пара «А + Б» |
| `groups.csv` | групи компонентів (27 груп із ТЗ) і позначка «активна» |

**Що вже заповнено заздалегідь** (статус «чернетка»): у `ingredients.csv` 93 поширені компоненти з довідковими даними: назва INCI, українська назва, синоніми, група. Це назви й належність до групи, а не поради. Стовпці з поясненнями й застереженнями порожні. Перевір і довідкові дані: якщо компонент віднесено не до тієї групи, виправ.

## Статуси і що бачить людина

| Статус | Коли ставити | Де показується |
|---|---|---|
| `перевірено` | фахівчиня перевірила весь рядок | у звичайному режимі і в демонстраційному |
| `чернетка` | рядок ще в роботі | лише в демонстраційному режимі, з позначкою «Чернетка: фахівець ще не перевірив цю картку» |
| `заготовка` | тексту ще немає зовсім | ніде |

Порожнє поле на екрані показується як «Інформація готується».

**Режим показу задає змінна `VITE_CONTENT_POLICY`.** Типово `demo` (показує й чернетки). Для справжніх користувачів на розгортанні постав `public`: тоді люди бачать лише перевірене.

Щоб поставити «перевірено», обов'язково заповни:
- компонент: «Назва українською», «Для чого», «Джерело»;
- правило: «Пояснення», «Джерело», і обидва компоненти чи групи в правилі теж мають бути «перевірено»;
- група: «Назва українською», «Джерело».

Без цього імпорт зупиниться й покаже, у якому рядку чого бракує.

**Коли заповнюєш рядок, заміни «Джерело»** на своє (наприклад, «Консультація косметолога Н. Н., 2026» або назва посібника). Рядки зі старим джерелом «Довідкові дані для перевірки…» автотест вважає незаповненими й перевіряє, що в них немає порад.

## Компоненти (`ingredients.csv`)

| Стовпець | Що писати | Обов'язково |
|---|---|---|
| id | можна лишити порожнім: створиться з INCI | ні |
| INCI | назва як на етикетці: `Niacinamide` | так |
| Назва українською | `Ніацинамід` | для «перевірено» |
| Синоніми | інші назви на етикетках: `Nicotinamide \| Vitamin B3` | ні |
| Групи | назви груп з таблиці нижче: `Цинк \| Сонцезахисні фільтри` | ні |
| Категорія | коротко: «зволожувальний компонент», «ексфоліант» | ні |
| Для чого | просте пояснення призначення | для «перевірено» |
| Властивості | кілька коротких пунктів через `\|` | ні |
| Застереження 1–3 | текст застереження | ні |
| Застереження N: для станів | кому саме (стани з таблиці нижче). Порожньо: для всіх | ні |
| Як застосовувати | особливості застосування | ні |
| Відомі взаємодії | інші компоненти з цієї ж таблиці (INCI або синонім) | ні |
| Підтримує цілі | цілі з таблиці нижче: показується як «потенційна користь» | ні |
| Джерело | звідки інформація | для «перевірено» |
| Статус | `перевірено`, `чернетка` або `заготовка` | ні (порожньо = чернетка) |
| Примітка | для себе, у застосунок не йде | ні |

## Правила сумісності (`compat-rules.csv`)

| Стовпець | Що писати |
|---|---|
| Компонент або група А, Б | компонент за INCI (`Retinol`) або групу за українською назвою (`AHA-кислоти`). Якщо назва збігається і з групою, і з компонентом, напиши `група: …` або `компонент: …` |
| Рівень | `обережно` (застереження) або `інформація` (лише до відома) |
| Лише в один час догляду | `так`: попереджати, тільки коли обидва вранці або обидва ввечері. `ні` або порожньо: попереджати завжди, коли обидва є в догляді (обережніший варіант) |
| Посилити для станів | стани, для яких попередження стає сильнішим |
| Посилити при реакціях | реакції з тесту, за яких попередження стає сильнішим |
| Пояснення | чому поєднання потребує уваги, простою мовою |
| Порада щодо часу | наприклад, «використовувати в різні дні» |
| Пріоритет | ціле число, більше = важливіше. Порожньо = 0 |
| Джерело, Статус, Примітка | як у компонентах |

Приклад рядка (вигаданий, лише для форми): А `AHA-кислоти`, Б `Ретиноїди`, рівень `обережно`, лише в один час `так`, посилити для станів `Чутлива`, пояснення «…», джерело «…», статус `чернетка`.

## Групи (`groups.csv`)

Стовпець «Активна група»: `так`, якщо група вважається активною (тоді застосунок шукає повтор активів і «багато активних засобів в один час», а порівняння засобів може сказати «схожа функція»). `ні` або порожньо: не активна. «Шаблони назв»: як розпізнавати назви без окремої картки, `*paraben` означає «закінчується на paraben».

## Як зберегти таблицю

- **Excel:** «Зберегти як» → «CSV UTF-8 (розділювач коми)» з тим самим ім'ям файлу. Не змінюй назви стовпців у першому рядку.
- **Google Sheets:** «Файл» → «Імпорт» (завантажити CSV), після правок «Файл» → «Завантажити» → «CSV» і поклади файл у `content/cosmetologist/` з тим самим ім'ям.

## Як перенести в застосунок (авторка)

```
npm run content:import -- --check    # лише перевірити таблиці
npm run content:import               # перевірити й записати файли контенту
```

Якщо є помилки, імпорт нічого не записує й показує таблицю, рядок і що не так. Якщо в терміналі замість літер дивні символи, спершу виконай `chcp 65001`.

Після успішного імпорту:
1. підніми `contentVersion` у `src/content/data/version.json` (наприклад, 0.2.0 → 0.3.0) і дату `updatedAt`;
2. `npm run content:audit` (оновить список у `CONTENT_TODO.md`);
3. `npm run check`;
4. коміт: `content: …`.
