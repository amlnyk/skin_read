# Документація

- `architecture/`: як влаштовано проєкт.
  - [ARCHITECTURE.md](architecture/ARCHITECTURE.md): шари, межі імпортів, структура папок і правила розкладки файлів.
  - [STACK.md](architecture/STACK.md): технології й чому вони.
  - [API.md](architecture/API.md): серверна функція розпізнавання фото.
  - [states.md](architecture/states.md): стани екранів (завантаження, порожньо, помилка).
  - [pwa.md](architecture/pwa.md): робота без інтернету й оновлення.
  - [decisions.md](architecture/decisions.md): журнал рішень за датами.
- `quality/`: перевірки й звіти.
  - [accessibility.md](quality/accessibility.md), [security-report.md](quality/security-report.md), [test-report.md](quality/test-report.md), [tz-compliance.md](quality/tz-compliance.md).
- `content/`: контент і робота косметолога.
  - [content-guide.md](content/content-guide.md): як заповнювати таблиці.
  - [content-inventory.md](content/content-inventory.md): що є в матеріалах авторки.
- `setup/`: налаштування репозиторію.
  - [ci-setup.md](setup/ci-setup.md), [setup-security.md](setup/setup-security.md).
