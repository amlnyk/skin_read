# features/settings

Налаштування, нагадування, згоди, керування даними (етап 10).

- `/profile/settings`: `SettingsPage` (які поля щоденника показувати; посилання на три підсторінки).
- `/profile/settings/reminders`: `RemindersPage` (лише перемикачі й час; реальних сповіщень ще немає).
- `/profile/settings/consents`: `ConsentsPage` (згода на фото: видно й можна відкликати).
- `/profile/settings/data`: `DataPage`: «Які дані зберігаються», експорт у JSON, імпорт з перевіркою,
  видалення категорій (`utils/dataCategories.ts`) і «Видалити все».
- Імпорт: файл перевіряється (`.json`, до 5 МБ, JSON, схема), показується, що в ньому є, і лише після
  підтвердження дані замінюються. Згода на фото з файлу не береться без окремої галочки.
- «Видалити все» залишає онбординг пройденим, щоб відразу можна було відновити копію.

Правила імпорту:
- ззовні цю фічу імпортують лише через `@/features/settings` (файл `index.ts`);
- усередині фічі імпорти відносні (`./`, `../`);
- можна імпортувати: `@/logic/*`, `@/store`, `@/content`, `@/lib/*`, `@/ui`, `@/i18n`, `@/schemas`, `@/types`;
- не можна: інші фічі, `@/app`.
