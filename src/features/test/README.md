# features/test

Екрани опитувальника. Усе керується даними з `content/questionnaire.json`: питання, тип відповіді, варіанти, exclusive-варіанти, умови показу `showIf`. Нове питання не потребує змін у коді екрана.

- `hooks/useTestFlow` зберігає чернетку (`testDraft`) після кожної відповіді; перезавантаження повертає на те саме питання;
- «Тест завершено» = `startedAt` заповнено, `currentQuestionId` = null; сирі відповіді лишаються в чернетці для розрахунку профілю (етап 4);
- екран результату (`TestResultPage`) поки заглушка;
- вільний текст варіантів «Інше» зберігається під ключем `<питання>:<варіант>:text` (`otherTextKey`).

Правила імпорту:
- ззовні цю фічу імпортують лише через `@/features/test` (файл `index.ts`);
- усередині фічі імпорти відносні (`./`, `../`);
- можна імпортувати: `@/logic/*`, `@/store`, `@/content`, `@/lib/*`, `@/ui`, `@/i18n`, `@/schemas`, `@/types`;
- не можна: інші фічі, `@/app`.
