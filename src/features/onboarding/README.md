# features/onboarding

Онбординг: привітання та вибір шляху (тест, швидкий старт, пропуск).

Правила імпорту:
- ззовні цю фічу імпортують лише через `@/features/onboarding` (файл `index.ts`);
- усередині фічі імпорти відносні (`./`, `../`);
- можна імпортувати: `@/logic/*`, `@/store`, `@/content`, `@/lib/*`, `@/ui`, `@/i18n`, `@/schemas`, `@/types`;
- не можна: інші фічі, `@/app`.
