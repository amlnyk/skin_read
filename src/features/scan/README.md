# features/scan

Сканер складу: вставлений текст і фото етикетки.

Правила імпорту:
- ззовні цю фічу імпортують лише через `@/features/scan` (файл `index.ts`);
- усередині фічі імпорти відносні (`./`, `../`);
- можна імпортувати: `@/logic/*`, `@/store`, `@/content`, `@/lib/*`, `@/ui`, `@/i18n`, `@/schemas`, `@/types`;
- не можна: інші фічі, `@/app`.

Фото етикетки (етап 11):
- `/scan/photo` (`PhotoPage`): камера або галерея, стиснення, попередній перегляд, окрема згода (`ConsentDialog`) перед першою відправкою, розпізнавання через `useServices().labelReader`;
- результат іде на той самий екран перевірки (`/scan/review`) через `location.state` (текст, назва, бренд, категорія, довіра, фото); фото зберігається на пристрої лише за позначкою користувача;
- кожна помилка має зрозуміле повідомлення й посилання «Ввести склад вручну»;
- кнопка на вході сканера залежить від прапорця `VITE_FEATURE_PHOTO_SCAN` (`Services.features.photoScan`).
