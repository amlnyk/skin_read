# features/compare

Порівняння двох засобів (етап 12).

- `/care/compare`: `ComparePage`. Вибір двох засобів із колекції або історії перевірок, ціни за бажанням (їх вводить
  користувачка, вони не зберігаються), дві колонки (на вузькому екрані одна), висновок словами й підпис про ефективність.
- Без профілю екран просить пройти тест. Засіб без складу не пропонується.
- Профіль аналізується тут само (`useProfileAnalysis`): `useChecks` лежить у фічі scan, а фічі не імпортують одна одну.

Правила імпорту:
- ззовні цю фічу імпортують лише через `@/features/compare` (файл `index.ts`);
- усередині фічі імпорти відносні (`./`, `../`);
- можна імпортувати: `@/logic/*`, `@/store`, `@/content`, `@/lib/*`, `@/ui`, `@/i18n`, `@/schemas`, `@/types`;
- не можна: інші фічі, `@/app`.
