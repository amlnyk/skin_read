# features/profile

Профіль користувача, екран результату тесту, історія й налаштування профілю.

- `ResultPage`: будує профіль із відповідей (`useProfileBuilder`); в екстреному режимі спершу лише `EmergencyScreen`, у режимі «до лікаря» зверху `DoctorBanner`. Профіль потрапляє в store лише після «Підтвердити профіль» (revision +1);
- `ProfilePage`: усі групи профілю, «Змінити» біля кожної (відповіді відновлюються з профілю через `answersFromProfile`, тест іде лише по цій групі: `/test?only=...`), «Пройти тест повторно», «Видалити чутливі дані» (стать і цикл);
- тексти типів, станів і повідомлень безпеки тільки з контенту; коли їх немає, показується «Інформація готується».

Правила імпорту:
- ззовні цю фічу імпортують лише через `@/features/profile` (файл `index.ts`);
- усередині фічі імпорти відносні (`./`, `../`);
- можна імпортувати: `@/logic/*`, `@/store`, `@/content`, `@/lib/*`, `@/ui`, `@/i18n`, `@/schemas`, `@/types`;
- не можна: інші фічі, `@/app`.
