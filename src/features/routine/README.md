# features/routine

Екран «Мій догляд»: питання про рутину, схеми ранку й вечора, список потрібних засобів.

Правила імпорту:
- ззовні цю фічу імпортують лише через `@/features/routine` (файл `index.ts`);
- усередині фічі імпорти відносні (`./`, `../`);
- можна імпортувати: `@/logic/*`, `@/store`, `@/content`, `@/lib/*`, `@/ui`, `@/i18n`, `@/schemas`, `@/types`;
- не можна: інші фічі, `@/app`.

Що де:
- `pages/RoutinePage.tsx`: вкладки Ранок, Вечір, Потрібні покупки; банер лікаря; примітки;
- `components/ScenarioChoice.tsx`: «Ні / Так / Частково / Пропустити» й вибір категорій, що вже є;
- `components/StepCard.tsx`, `RoutineTab.tsx`: кроки рутини списком, один рядок на крок зверху вниз: галочка «виконано сьогодні», назва (тап відкриває модальне вікно), частота, статус і помітка «Є застереження»; у вікні застереження для профілю, час, призначення, «на що звернути увагу» та кнопки вгору, вниз, прибрати; додавання кроку;
- `components/ShoppingNeeds.tsx`: групи потреб, короткі картки («готово», «прибрати», перехід у сканер, застереження, причина); призначення й «на що звернути увагу» у модальному вікні «Докладніше»;
- `hooks/useCare.ts`: збирає все з store й `logic/routine`;
- `pages/AnalysisPage.tsx` (`/care/analysis`): «Аналіз мого догляду», список спостережень про весь набір засобів; `components/ObservationCard.tsx`, `SeverityIcon.tsx`; `hooks/useRoutineAnalysis.ts`; `utils/describeObservation.ts` перетворює спостереження на слова з контенту й словника (немає тексту, то «Інформація готується»);
- `utils/describe.ts`: id з логіки в тексти. Немає тексту в контенті, тоді «Інформація готується»;
- `utils/today.ts`: сьогоднішня дата користувача.

У store зберігається лише те, що змінив користувач: кроки, позначки, стан потреб. Призначення, застереження й потреби рахуються щоразу.
