# features/design

Тимчасова сторінка `/design` для перевірки дизайн-системи (кольори, шрифти, логотип, фони)
на телефоні й на Vercel Preview. Вона доступна і в продакшн-збірці, бо авторка перевіряє
дизайн за посиланням; завантажується окремо (lazy) і не впливає на інші екрани.
Коли дизайн-систему буде затверджено, сторінку можна прибрати (рішення від 2026-11-26).

Правила імпорту:
- ззовні цю фічу імпортують лише через `@/features/design` (файл `index.ts`);
- можна імпортувати: `@/ui`, `@/i18n`;
- не можна: інші фічі, `@/app`, store, logic, content.
