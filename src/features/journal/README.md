# features/journal

Щоденник шкіри (етап 10): запис, історія, видалення, пропозиція оновити профіль.

- `/journal`: `JournalPage` (форма запису, список, банер «Хочеш оновити профіль?»).
- Усе заповнення необовʼязкове. Жодних нагадувань про «пропущені дні».
- Поля про цикл і гоління показує `journalFieldVisibility` (логіка в `@/logic/journal`).
- Банер лише питає. «Оновити профіль» відкриває питання про стан шкіри з уже відміченим станом;
  профіль змінюється (revision +1) після підтвердження на екрані результату. «Не зараз» ховає банер на 7 днів.
- Нотатки та інші тексти показуються лише як текст.
- Етап 12: `CalendarView` (місяць, позначка на дні із записом, дотик відкриває запис) і `TrendChart` (30 днів одного
  симптому, власний SVG; день без запису це розрив, не нуль; маркери нових засобів і змін у догляді; підпис
  «Збіг у часі не означає причини.»). Показуються, коли є хоча б один запис.

Правила імпорту:
- ззовні цю фічу імпортують лише через `@/features/journal` (файл `index.ts`);
- усередині фічі імпорти відносні (`./`, `../`);
- можна імпортувати: `@/logic/*`, `@/store`, `@/content`, `@/lib/*`, `@/ui`, `@/i18n`, `@/schemas`, `@/types`;
- не можна: інші фічі, `@/app`.
