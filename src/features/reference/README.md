# features/reference

Довідник: пошук і картки компонентів, групи, вкладка «Освітні матеріали» (поки порожній стан).

- `pages/ReferencePage.tsx`: вкладки, пошук, фільтр за категорією, перегляд за групами;
- `components/IngredientCard.tsx`: картка компонента (назва, INCI, синоніми, категорія, пояснення, властивості, застереження, застосування, взаємодії, джерело); поле без тексту показує «Інформація готується»; жодних міток «добре/погано» і червоно-зелених кольорів;
- `components/GroupList.tsx`: групи, що розгортаються до опису й карток;
- `components/EducationPlaceholder.tsx`: порожній стан освітньої вкладки;
- пошук це чиста функція `searchIngredients` з `@/logic/inci`.

Правила імпорту:
- ззовні цю фічу імпортують лише через `@/features/reference` (файл `index.ts`);
- усередині фічі імпорти відносні (`./`, `../`);
- можна імпортувати: `@/logic/*`, `@/store`, `@/content`, `@/lib/*`, `@/ui`, `@/i18n`, `@/schemas`, `@/types`;
- не можна: інші фічі, `@/app`.
