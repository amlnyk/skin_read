# features/reference

Довідник: компоненти, групи, правила сумісності.

Правила імпорту:
- ззовні цю фічу імпортують лише через `@/features/reference` (файл `index.ts`);
- усередині фічі імпорти відносні (`./`, `../`);
- можна імпортувати: `@/logic/*`, `@/store`, `@/content`, `@/lib/*`, `@/ui`, `@/i18n`, `@/schemas`, `@/types`;
- не можна: інші фічі, `@/app`.
