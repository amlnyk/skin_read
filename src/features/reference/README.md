# features/reference

Довідник: пошук і картки компонентів, групи, вкладка «Освітні матеріали» (поки порожній стан).

- `pages/ReferencePage.tsx`: вкладки, пошук, фільтр за категорією, швидкий фільтр за групою (кнопки «Усі / група / Інші» йдуть одна за одною й переносяться на новий рядок; обрана група відкрита одразу; під час пошуку фільтр прихований), перегляд за групами;
- `components/IngredientList.tsx`: список назв компонентів (назва та INCI в рядку); тап по рядку відкриває картку в модальному вікні (`@/ui` `Modal`), закрити можна кнопкою або Escape;
- `components/IngredientCard.tsx`: картка компонента (її показує модальне вікно, назва стоїть у заголовку вікна) (назва, INCI, синоніми, категорія, пояснення, властивості, застереження, застосування, взаємодії, джерело); поле без тексту показує «Інформація готується»; жодних міток «добре/погано» і червоно-зелених кольорів;
- `components/GroupList.tsx`: групи, що розгортаються до опису й списку компонентів;
- `components/EducationPlaceholder.tsx`: порожній стан освітньої вкладки;
- пошук це чиста функція `searchIngredients` з `@/logic/inci`;
- зверху сторінки посилання на `/reference/compat` (перевірка сумісності, фіча `compat`); тест сторінки обгортає її в `MemoryRouter`.

Правила імпорту:
- ззовні цю фічу імпортують лише через `@/features/reference` (файл `index.ts`);
- усередині фічі імпорти відносні (`./`, `../`);
- можна імпортувати: `@/logic/*`, `@/store`, `@/content`, `@/lib/*`, `@/ui`, `@/i18n`, `@/schemas`, `@/types`;
- не можна: інші фічі, `@/app`.
