# features/home

Екран «Сьогодні» (нове ТЗ, екран 08):

- без профілю: запрошення пройти тест;
- з профілем: банер «до лікаря» за потреби; ранок і вечір чеклістами (`components/TodayChecklist`), виконаний крок закреслюється; «Як шкіра сьогодні?»; посилання «Календар» (`/journal`); кнопка «Зберегти»;
- до «Зберегти» нічого не записується; потім позначки йдуть у `routineLog`, самопочуття в запис щоденника за сьогодні;
- нової логіки немає: `useHomeSummary` читає рутину, журнал і `doneStepIds`;
- без оцінок, відсотків, балів і серій.

Правила імпорту:
- ззовні цю фічу імпортують лише через `@/features/home` (файл `index.ts`);
- усередині фічі імпорти відносні (`./`, `../`);
- можна імпортувати: `@/logic/*`, `@/store`, `@/content`, `@/lib/*`, `@/ui`, `@/i18n`, `@/schemas`, `@/types`;
- не можна: інші фічі, `@/app`.
