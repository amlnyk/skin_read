# features/home

Головний екран (ТЗ, розділ 27). Лише підсумок, деталі на своїх екранах:

- без профілю: запрошення пройти тест, швидкий вхід у сканер, медичне застереження;
- з профілем: банер «до лікаря» за потреби; тип шкіри й стан зараз (назви з контенту); кількість обмежень; кроки ранкового або вечірнього догляду (до 15:00 ранок) і скільки виконано сьогодні; базові потреби, яких бракує; швидкі дії (сканер, щоденник);
- нової логіки немає: `useHomeSummary` викликає ті самі `analyzeSavedProfile` і `buildShoppingNeeds`, що й екрани догляду;
- без оцінок, відсотків і балів.

Правила імпорту:
- ззовні цю фічу імпортують лише через `@/features/home` (файл `index.ts`);
- усередині фічі імпорти відносні (`./`, `../`);
- можна імпортувати: `@/logic/*`, `@/store`, `@/content`, `@/lib/*`, `@/ui`, `@/i18n`, `@/schemas`, `@/types`;
- не можна: інші фічі, `@/app`.
