# features/compat

Перевірка сумісності компонентів: «Довідник → Перевірка сумісності» (`/reference/compat`).

Що тут є:
- `pages/CompatCheckerPage`: вибір двох і більше компонентів чи груп, необовʼязковий час (ранок або вечір), результати;
- `components/IngredientPicker`: пошук і вибір (кнопки з `aria-pressed`);
- `components/CompatResultCard`: картка однієї пари. Статус показано іконкою і словами, без кольорових сигналів;
- `labels.ts`: назви компонентів і значень профілю з контенту. Якщо тексту немає, екран пише «Інформація готується».

Екран нічого не вирішує сам. Усі висновки дає `logic/compat`, а правила лежать у `content/compat-rules.json`.
Слів «безпечно» і «заборонено» тут немає: максимум, що можна сказати, це «не виявлено відомих конфліктів у межах наявних даних».

Правила імпорту:
- ззовні цю фічу імпортують лише через `@/features/compat` (файл `index.ts`);
- усередині фічі імпорти відносні (`./`, `../`);
- можна імпортувати: `@/logic/*`, `@/store`, `@/content`, `@/lib/*`, `@/ui`, `@/i18n`, `@/schemas`, `@/types`;
- не можна: інші фічі, `@/app`.
