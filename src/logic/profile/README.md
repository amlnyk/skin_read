# logic/profile

Побудова профілю з відповідей і контенту: `buildProfile(answers, content, now, identity)`.
Без мовної моделі: передбачувана система правил.

- `extractProfile.ts`: єдине місце, яке читає відповіді про стать і цикл (копіює їх у профіль);
- `rules/`: по одному правилу на файл; пріоритети з ТЗ (розділ 10), 1 найсильніший.
  Слабше правило не перебиває сильніше (`setModeIfFree`);
- `applyRestrictions.ts`: обмеження прибирає рекомендацію нижчого пріоритету (для етапу 5);
- `effectiveGoals.ts`: цілі, що можуть керувати кроками (підліткам без антивікової мети).

Результат не містить жодного згенерованого тексту: `textBlocks` це посилання на id записів
контенту (`contentId: null` означає «Інформація готується»), `notes` це id службових приміток.

Правила: чисті функції.
- можна імпортувати: `@/schemas`, `@/types`, `@/lib/result` і сусідні модулі logic через `../safety`, `../test`;
- не можна: react, DOM, store, features, ui, інші модулі lib, fetch;
- не можна `Date.now()`, `new Date()` без аргументів, `Math.random()`: час і id приходять аргументами;
- контент приходить аргументом, а не імпортом.
