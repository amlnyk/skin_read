# logic/compare

Порівняння двох засобів (етап 12).

- `compareProducts(input)`: та сама категорія, спільні й окремі групи та компоненти (лише розпізнані позиції),
  результат `analyzeProduct` для кожного засобу, `similarity` (`likely_similar_function`, `partially`, `different`,
  `insufficient_info`) і `priceDifference`.
- `priceDifference` є лише для обох введених цін (> 0) і вказаної валюти; без них поля немає (не 0). Цін, наявності й
  назв альтернатив функція не вигадує.
- `likely_similar_function` потребує спільної групи з `active: true` у контенті. У справжньому контенті `active` ще
  не виставлено (чекає косметолога).
- Схожий склад не означає однакову ефективність: підпис про це показує екран.

Правила: чисті функції.
- можна імпортувати: `@/schemas`, `@/types`, `@/lib/result`;
- не можна: react, DOM, store, features, ui, інші модулі lib, fetch;
- не можна `Date.now()`, `new Date()` без аргументів, `Math.random()`: час і id приходять аргументами;
- контент приходить аргументом, а не імпортом.
