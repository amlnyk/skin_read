# logic/routine

Побудова базової рутини і списку потрібних засобів (етап 5).

Що тут є:
- `buildBaseRoutine(profile, analysis, ownedCategories, content)`: ранок і вечір. Ранок: очищення (за потреби), зволоження, сонцезахист. Вечір: очищення, зволоження. Сонцезахист завжди вранці. Тоніки, есенції, сироватки не обов'язкові;
- `selectOptionalSteps`: додатковий крок лише в режимі `standard`, без медичних приміток, без конфлікту з обмеженнями, не більше одного на слот, для неповнолітніх без антивікового. Кандидати беруться лише з `content.routineSteps`; немає перевірених кандидатів, то немає й кроку;
- `explainStep`: призначення, компоненти, особисті застереження. Не зберігається, рахується щоразу;
- `buildShoppingNeeds`: групи `base`, `missing`, `optional`, `not_now`;
- `moveStep`, `removeStep`, `addStep`: редагування кнопками;
- `markStep`, `doneStepIds`: позначка «виконано» на один день.

Правила: чисті функції.
- можна імпортувати: `@/schemas`, `@/types`, `@/lib/result`, сусідні модулі logic через `../`;
- не можна: react, DOM, store, features, ui, інші модулі lib, fetch;
- не можна `Date.now()`, `new Date()` без аргументів, `Math.random()`: час і id приходять аргументами;
- контент приходить аргументом, а не імпортом.
