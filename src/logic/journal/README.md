# logic/journal

Підсумки щоденника й пропозиція оновити профіль (етап 10).

- `suggestProfileUpdate(entries, profile, now, config)`: чи є привід запитати «Хочеш оновити профіль?».
  Так, якщо за останні 14 днів той самий симптом має інтенсивність 2–3 щонайменше у 4 записах, а
  відповідного стану ще немає в профілі. Пороги в `logic/config.ts`. Функція лише питає: нічого не
  стверджує про причину й нічого не змінює.
- `SYMPTOM_CONDITION`: який стан профілю відповідає симптому (лише для попередньо відміченої відповіді;
  **пропозиція, чекає косметолога**).
- `journalFieldVisibility(profile, settings)`: які необовʼязкові поля показує форма (цикл, гоління).
- `entryHasContent`, `buildEntry`, `sortEntries`, `withoutCyclePeriod`: чернетка запису, збереження, порядок.
- `dates.ts`: календар у UTC; час приходить аргументом.
- `calendar.ts` (етап 12): `monthGrid` (тиждень з понеділка), `shiftMonth`, `monthOf`, `entriesByDate`.
- `trend.ts` (етап 12): `trendSeries` (30 днів, день без запису це `null`, не 0), `runsOf` (відрізки лінії без
  розривів), `trendEvents` (нові засоби й зміни в догляді), `mostRecordedSymptom`.

Правила: чисті функції.
- можна імпортувати: `@/schemas`, `@/types`, `@/lib/result`;
- не можна: react, DOM, store, features, ui, інші модулі lib, fetch;
- не можна `Date.now()`, `new Date()` без аргументів, `Math.random()`: час і id приходять аргументами;
- контент приходить аргументом, а не імпортом.
