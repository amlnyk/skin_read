# Скрипти етапів

`setup-*.ps1` це журнали етапів розробки: кожен колись перевіряв і фіксував свій етап.
Повторно їх не запускають. Шляхи до файлів усередині старих скриптів описують проєкт на
момент етапу (до перенесення файлів у теперішню структуру, див.
`docs/architecture/ARCHITECTURE.md`, розділ 3).

Робочі команди проєкту в `package.json` (`npm run check`, `npm run content:import`,
`npm run content:audit`), їхній код у `scripts/content/`.
